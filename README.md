# O que mais gosto em Manaus

Projeto estático da disciplina de Engenharia de Software. A página reúne fotos e indicações de lugares para visitar em Manaus.

Abra `index.html` em um navegador para visualizar a versão principal. A versão em `site/index.html` inclui um vídeo adicional. Ao alterar a navegação, a galeria ou o estilo, confira as duas versões.

O projeto não requer instalação, compilação ou servidor. As fontes do Google e os vídeos do YouTube precisam de conexão com a internet.
